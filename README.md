# Benchmark – 2D Survival Game

## Aufgabe

> Entwickle mit **Python und Pygame** ein möglichst gutes, vollständig spielbares **2D-Top-down-Minecraft-Survival-Spiel** auf einem **vollständig sichtbaren 32×32-Kachelraster**, vergleichbar mit einem Minesweeper-Spielfeld.

Wie du die Spielidee interpretierst und umsetzt, liegt bei dir. Triff eigenständig alle notwendigen Entscheidungen zu Spielmechaniken, Darstellung, Bedienung, Architektur, Qualitätssicherung und Priorisierung.

Organisiere die Entwicklung autonom und liefere im Rahmen des jeweils zugeteilten Budgets das bestmögliche Ergebnis.

## Benchmark-Hinweise

- Die konkreten Phasenaufträge sowie Zeit- und Kontingentgrenzen werden **separat zum jeweiligen Phasenstart** mitgeteilt.
- Dieses Repository ist die **unveränderte Ausgangsvorlage**, kein gemeinsamer Arbeitsbereich. Entwickle ausschließlich in deinem zugewiesenen Ergebnis-Repository.
- Sorge dafür, dass dein Ergebnis aus einem frischen Checkout nachvollziehbar gestartet werden kann, und dokumentiere die nötigen Schritte.
